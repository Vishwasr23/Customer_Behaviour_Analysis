# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, SQL, and Power BI to identify purchasing patterns, customer segments, product performance, and factors influencing revenue.

The analysis starts with raw customer shopping data, performs data cleaning and exploratory analysis using Python, uses SQL to answer key business questions, and presents the findings through an interactive Power BI dashboard.

The objective is to transform raw customer transaction data into actionable business insights that can support decisions around customer retention, promotions, product performance, and revenue generation.

---

## 🎯 Business Objectives

The project focuses on answering key business questions such as:

- Which customer segments generate the most revenue?
- Do male and female customers contribute differently to revenue?
- Do customers who receive discounts still generate significant spending?
- Which products have the highest average review ratings?
- How does shipping type affect average purchase amount?
- Do subscribed customers spend more than non-subscribed customers?
- Which products have the highest percentage of discounted purchases?
- How can customers be segmented based on previous purchases?
- What are the top-selling products within each category?
- Are repeat buyers more likely to have an active subscription?
- How does revenue vary across customer age groups?
